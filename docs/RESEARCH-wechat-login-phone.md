# 微信小程序登录与手机号获取调研报告

> 调研日期:2026-09-12。方法:两轮工作流(官方文档实抓 + 本项目前后端代码盘点),所有高风险论断经反驳式核验,被更正的说法见 §9。
> 依据均为当日从 developers.weixin.qq.com / 腾讯客服官方页 / 云厂商官方公告抓取的一手文本。

## 0. 结论先行

1. **微信登录现在就能做**:wx.login → code2Session → openid → 自有 token。免费、无认证门槛、个人主体完全可用。后端 tsa-api 已用 Sa-Token,这是纯增量开发。
2. **「微信一键授权手机号」对个人主体永久封死**:官方原文「目前该接口针对非个人主体,且完成了认证的小程序开放」——双重门槛缺一不可,个人主体花 30 元完成个人认证也解不开(有社区实证案例)。微信侧不存在任何个人主体可用的官方取号/实名能力(人脸核身、卡券、微信支付、web-view 全部要求非个人主体)。
3. **主体变更是保住现有小程序的唯一升级路**:个人→组织(含社会团体)走「小程序主体变更」,**appid 不变、账号不注销、用户与已发小程序码保留**(后者系由 appid 不变推得);300 元审核费 + 个人→组织须走**公证书**路径(法人扫脸仅限双方均为企业/个体户)。变更完成后须:重报服务类目并 7 天内提审新代码、以乡会主体重新微信认证(300 元,认证前「其他组织」不能提审)、注销备案后重新备案。
4. **比手机号更硬的约束是类目**:个人主体没有「社交-社区/论坛」类目可报——现有**社区动态功能在个人主体下无合法类目**,公开会员名册同样有合规风险。产品要长期做,主体变更几乎是必选项,而非手机号功能的可选项。
5. 不变更主体的过渡方案:**手机号手动输入 + 自建短信验证码**(协会若有《社会团体法人登记证书》,可用云账号+协会名义「他用资质」报备签名,约 0.045 元/条,预留 2-4 周报备周期)或**弱核验组合**(openid 管理端认领 + 邀请码,零采集零成本)。
6. 时间预算:主体变更(≈1-2 周,含公证)+ 重新认证(1-5 工作日)+ 提审 + 备案(管局最长 20 工作日)串行,**整体 4-6 周**。

## 1. 官方链路现状(2026-09)

### 1.1 登录主链路
- `uni.login` 拿 code(**5 分钟、一次性**,与手机号 code 互不通用)→ 服务端 `GET /sns/jscode2session?appid&secret&js_code&grant_type=authorization_code` → openid(+unionid,若已绑开放平台)+ session_key。
- session_key **绝不下发前端**(官方明文禁止);本项目一期不消费它,**不落库**。
- 错误码分支:40029(无效 code,前端重新 login 重试一次)/ 45011、45009(频率限制,退避+合并并发)/ 40226(风控)/ 40013、40125、40164(配置错误,按运维告警处理)。
- 自有 token 失效用 `checkSession` 或直接重登;**401 → 静默重登 → 重放原请求** 优于跳登录页。
- access_token 服务端调用推荐 `POST /cgi-bin/stable_token`(普通版 /cgi-bin/token 并未下线,官方仅「推荐替代」;40164 两版通用,89503/89506/89507 是 stable_token 的管理员确认类错误)。

### 1.2 手机号组件(变更后才会用到)
- 现行方式:`<button open-type="getPhoneNumber">` → `e.detail.code` → 服务端 `POST /wxa/business/getuserphonenumber` → purePhoneNumber + watermark(须校验 watermark.appid == 本 appid)。
- 旧的 encryptedData+iv+session_key 解密:**软废弃**——官方原文「旧方式目前可以继续使用,但建议开发者使用新方式」,无停用日期;新项目不引入。
- 收费(2023-08-28 起至今未变):快速验证 **0.03 元/次**、实时验证 0.04 元/次;每账号 1000 次体验额度(正式/体验/开发版共用)。免费仅限「微信认证主体类型=政府/非营利组织」等——**官方对「非营利组织」是封闭枚举(基金会、村居委会、外国机构驻华代表处),「社会团体」是并列独立取值,默认按 0.03 元/次计费**;最终以后台「微信认证主体类型」字段实际值+客服工单为准。
- 虚拟测试号段 **12066600001~04**:开发者工具/云测返回假号,匹配名册永不命中——真链路必须真机+真实认证账号。
- 拒绝授权后 10 秒内重复调用会被平台直接失败,不做自动重试。

## 1.5 社区/UGC 功能专项核验(2026-09-12 晚间第二轮,逐字官方文本+9 论断核验全过)

**结论:个人主体下「用户发布+他人可浏览」的社区功能不存在任何合规路径,「仅会员可见」不豁免。**

- 类目表实锤:个人主体仅 9 个一级类目(物流/教育/交通/生活/餐饮/旅游/工具/商业服务/体育),「社交」整一级(社区/论坛、笔记、问答等 9 个二级)只存在于非个人主体节;后台对个人主体根本选不到(配置级封禁)。社区/论坛资质需《非经营性互联网信息服务备案核准》或机关《统一社会信用代码证》,个人均无法持有。
- 官方判定句(图片处理类目备注原文):「如提供传播和公开访问服务,属于社交范畴,需选择【社交-笔记】类目」——**定性看功能实质,不看可见范围**。
- 「豁免」不存在:《运营规范》全文 37,803 字逐字检索,「豁免/仅会员/特定人群/内部/圈子」零命中;反向加重——5.19 把「对不同用户群体展示不同类目内容」定性为**对抗行为**(限分享/被搜索直至永久下架,株连同主体及关联主体、累计升档);拒绝情形 3.1.4/3.3.4 要求会员墙功能必须向测试号完整开放;备案层「个人备案:网络社交不建议选择」同步封堵。
- 唯一合规变体:UGC 仅本人可见(日记/收藏/备忘录——官方原文「不涉及用户原创内容的传播及公开访问」)。
- 官方置顶帖给的路只有两条(逐字):「1、申请企业主体小程序,补充对应的社交类目后合规提审;2、或自查代码,移除社交服务相关内容(评论、发布、动态、社区、论坛等入口)后提审」。申诉只能纠误判,不能翻规则。
- **⚡ 关键解锁:「企业」档包含个体工商户**(官方注册文档主体类型表:个人/企业/**企业(个体工商户)**/政府/媒体/其他组织)。注册个体户 → 属非个人主体 → 可办单位 ICP 备案 → 可报社交类目(首审经属地互联网主管机关,约 7 天)→ 亦可完成微信认证后解锁 getPhoneNumber。个体户注册成本低、周期 3-7 工作日,**可能比等挂靠方快一个量级**。认证费「个体户 30 元/年」系第三方口径,以 MP 后台实价为准。
- 待办核实(选个体户路之前):①小程序名称含「校友会/乡会」字样,个体户主体提报名称审核是否要求协会授权文件;②个体户做「非经营性ICP备案核准」的实操通案;③协会运营方与个体户注册人的信任/归属安排。

## 2. 出路对比

| | A 主体变更(个人→社会团体) | B 自建手机号+短信验证码 | C 弱核验(openid 认领+邀请码) |
|---|---|---|---|
| 前提 | 协会有《社会团体法人登记证书》 | 有证书→协会名义签名(他用资质);无证书→通用签名/「短信认证」产品,观感降级 | 无 |
| 一次性成本 | 300 审核费 + 公证费(数百元) + 认证 300 + 备案重做 | 签名/模板报备 2-4 周人力 | 低 |
| 持续成本 | 认证年审 300/年 + 0.03 元/次(1000 次/年免费额度对乡会量级≈够用) | ≈0.042-0.05 元/条,年发送千级=几十元 | 0 |
| 解锁 | 手机号组件、社区类目、微信支付、web-view、订阅触达 | 仅手机号 | 无 |
| appid/用户/码 | 保留 | 保留 | 保留 |
| 周期 | 4-6 周(串行关键路径) | 2-4 周(报备) | 即时 |
| 主要风险 | 类目失效 7 天内须完成新代码提审上线,逾期 API 失效/下架风险 | 个人云账号频控不可调(腾讯云);手机号留存 PIPL 责任 | 邀请码转发泄露(缓解:一码一绑 openid、一次性) |
| 适配现有契约 | `/tsa/auth/verify-phone {code}` 原契约即最终形态 | 契约需加变体 `{phone, smsCode}` | 新契约 `{inviteCode}` 或认领短码 |

**推荐**:A 为主干(社区类目这条比手机号更刚需),A 落地前用 C 顶着(零成本零合规风险);B 只在「协会已登记但变更短期无望」时作为中间档。

### A 路主体变更要点(按核验更正后口径)
- 入口:MP 后台【设置 → 基本信息 → 主体信息 → 小程序主体变更】。
- 方向:个人→组织支持;**不可逆**(目标主体不支持个人)。与「账号迁移」是两种能力,勿混(迁移 appid 变、要求相同/关联主体)。
- 流程五步:同意须知 → 填资料 → 授权验证(**个人→组织需上传公证书扫描件**;法人扫脸仅限双方均为企业/个体户)→ 支付 300 元(成败不退,个人方仅电子票)→ 第三方审核(约 7 工作日,30 天内 3 次补材料机会)→ 审核通过后管理员 **7 天内**扫码确认并签新协议,逾期重新缴费。
- 前置排雷:微信支付须先解绑所有非目标主体商户号(绑了支付服务商的不支持变更);广告主余额清零;插件所需类目须被新主体类目覆盖。
- 完成后强制动作:原类目全部失效→重报;**7 天内完成新代码版本审核及上线**;公众号关联超上限 7 天内解绑;**注销备案→以新主体重新备案**(官方备案 FAQ 口径)。
- 变更后仍非立即可用手机号组件:「其他组织」**必须完成微信认证(300 元、1-5 工作日、年审制)才能提交发布审核**,认证成功后方可购资源包调用。

### B 路自建短信要点
- 通道:阿里云短信(按量 0.045 元/条起)/ 腾讯云(套餐包 0.041-0.050);**短信认证**产品(免资质通用签名,约 0.042 元/次,不支持自定义签名)。
- 签名实名报备 2025 年起收紧:个人身份「自用资质」两家云均不再受理(腾讯云 2025-09-18 起)——协会名义签名必须走「他用资质」= 协会证照 + 盖章授权委托书;无登记证书则只剩通用签名(短信【】内无协会名)。
- 报备周期:平台 2 小时-2 工作日 + 运营商 7-10 工作日。
- 防刷:发码前图形验证码、单 IP 限流、日阈值告警;腾讯云个人账号**不可自助调频控**。
- 审核合规:平台无「个人主体不得收集手机号」禁令,管的是方式——手机号仅在用户主动的「入会核验」动作收集、可拒绝、页面标注用途;隐私指引句式「为了会员身份核验,开发者将在获取你的明示同意后,收集你的手机号」;有真实案例因「无游客可浏览」被拒——**保持公开内容免登录**。

### C 路弱核验要点
- 主干:wx.login → openid 建档(已有 code2Session);管理员按名册批量导入并生成认领短码,用户点开绑定;
- 门槛:邀请码/会员编号(一码一绑、一次性);
- 完全不采集新个人信息,审核风险最低;核验强度弱,适合「闸门防君子」的乡会场景。

### 灰产红线(绝对禁止)
- 运营商一键取号 SDK 不支持微信小程序(阿里/友盟/网易云信官方明言,腾讯云号码认证停止新接入);
- web-view 内嵌 H5 取号:个人主体三层封死,路径不存在;
- 三要素/在网/号码数据接口:违反 PIPL,情节严重触刑法 253 条之一;
- 提审隐藏取号逻辑:按规避审核处理,限能力/封号。

```

   App.onLaunch 或 token 失效:uni.login → code

   chooseAvatar + nickname 输入,头像临时路径立即 uni.uploadFile 持久化。
```

| (A 路)社区类目整改 | 变更完成前公开 UGC 无合法类目——过渡期社区页考虑仅登录会员可见/暂停公开,或与类目顾问确认「企业管理」类工具化包装可行性 |

## 6. 账号与合规 checklist(★=行政侧,非写代码)

1. ★ **确认协会登记状态**:是否有《社会团体法人登记证书》?——决定 A/B 路可行性与签名报备方式的第一步。
2. ★ 主体变更:备证书、双方签章+**骑缝章**的申请函、**公证**(个人→组织必经)、解绑商户号/清零广告余额;300 元不退。
3. ★ 微信认证(变更后):社会团体 300 元/次·年、1-5 工作日、年审列入运营日历(逾期→认证终止→手机号链路+提审能力失效)。
4. ★ 小程序备案 + 域名 ICP 备案(两件事;变更后旧备案须注销重办;未备案发布报 errcode 86369;回访电话 0755 别漏接)。
5. ★ 隐私保护指引:声明「收集你的手机号/昵称/头像/位置」逐项目的与期限;未声明组件直接禁用(errno 112),补充约 5 分钟生效。
6. ★ 手机号资源包:乡会(社会团体)默认计费,先用 1000 次体验额度验证用量;免费资格以「微信认证主体类型」后台实值+客服工单为准。
7. ★ 服务器出口 IP 加白名单(40164);request 合法域名仅 https、月度修改次数有限,上线窗口一次配齐。
8. ★ 开放平台账号绑定(为 unionid 与服务号矩阵预留,免费)。
9. ★ 提审材料:体验账号(能命中名册)+ 录屏 + 使用人群标注(闸门场景官方 FAQ 要求)。
10. ★ 名册用途授权话术:会员登记表/章程补「用于小程序内核验」。

## 7. 风险与坑(精选)

- 两个 code 严格互斥、均 5 分钟一次性,禁止乐观重试(40163/40029)。
- bindgetphonenumber 回调里再调 wx.login 会刷新 session_key(新链路虽不依赖,登录时序仍建议提前完成)。
- 闸门设计的官方文本依据是「企业内部/特定人群」类比条款,**无过审承诺**;违规后果不止提审被拒,可至手机号能力封禁/封号(运营规范 5.12)。
- 后端 `verify-phone` 现 mock-mode:联调真实链路前确认关闭。
- 45011/45009 清缓存重试无效(平台侧限频)。
- 「个人主体不可微信认证」是 2018-2023 旧表述,现行政策可认证(约 30 元/年)但**不解锁**手机号/web-view/支付。

## 8. 分期建议

- **第一期(现在,纯代码)**:后端 wechat-login + user/me + stable_token + unionid 列;前端真登录 + 401 静默重登 + 资料完善页;闸门走 C 路(邀请码/openid 认领);隐私声明、开放平台绑定同步做。
- **第二期(行政关键路径 4-6 周)**:主体变更 → 重新认证/类目/备案 → verify-phone 切 getPhoneNumber 真链路(真机联调)→ 社区类目合规化 → 微信支付/订阅触达按需。
- **暂缓**:session_key 落库、实时验证组件、长期订阅、第三方平台代调用。

## 9. 调研中被核验更正的点(勿再采信原说法)

- getUserProfile 匿名化截止:**2022-11-08**(非 10-25);<2.27.1 基础库有兼容豁免;「chooseAvatar 是唯一正确方式」属推断,官方措辞是「可以使用」。
- open-data 回收(2022-02-21)公告链接应为 000e881c…,且现行文档页不印日期。
- 手机号计费生效日只有 **2023-08-28**(「08-26」系媒体转述);实时验证 0.04 元/次;套餐集采可折至 ≈0.026。
- 「社会团体是否免单」:官方封闭枚举表明社团 ∉ 非营利组织 → **默认计费**(后台字段值仅作付款前核对)。
- 主体变更「双方管理员扫码」说法有误:授权验证环节个人→组织走**公证书**,付费后审核通过才由管理员限时确认(7 天)。
- 「变更期间可正常使用」无官方明文,不作承诺。
- 「账号迁移要求相同/关联主体」不是「不可逆」的论据;不可逆的官方依据是主体变更条件第 3 条(目标主体不支持个人)。
- 「getUserOpenData/getUserSessionInfo」从未是微信官方接口,系臆造/第三方命名。
- stable_token:普通版**并未下线**,仅官方推荐替代;40164 是两版通用错误码。
- 变更后备案口径出自官方备案 FAQ「暂不支持变更备案,需注销后重新备案」(该页为 JS 渲染,引用经两个核验 agent 交叉,建议办理时以备案系统实时提示复核)。
